Introduction

The lecture introduced inhibition, one of the three core executive functions, and the Stroop task as a measure of it. In this practical, each participant measures their own inhibition cost, and the class data are used to determine whether the inhibition cost is statistically significant. The analysis follows the same steps as for the spatial cueing effect.

Aim

To measure the Stroop inhibition cost in each participant, and to determine whether the class’s mean inhibition cost is statistically significant.

Materials

  • A computer in the teaching room, with a keyboard
  • LINK 1 below, to the Stroop task (PsyToolkit)
  • LINK 2 below, to the form in which results are recorded
  • LINK 3 below, to the class data workbook (view only)

TASK 1 · The Stroop task

  1. Open the task: LINK 1, and select the option to run the demonstration.
  2. Read the instructions on screen. On each trial, a colour word is presented in a coloured ink. The response is to the colour of the ink, not to the word.
  3. Respond as quickly and as accurately as possible.
  4. At the end, the summary reports the response time for congruent trials (word and ink colour match) and for incongruent trials (word and ink colour differ). Note both values (ms).

TASK 2 · Submission of results

Open the form at LINK 2 and enter the two values noted in Task 1.

TASK 3 · The individual inhibition cost

Calculate the inhibition cost:

inhibition cost = mean response time on incongruent trials − mean response time on congruent trials

A positive value indicates that responses were slower when the word and the ink colour conflicted.

TASK 4 · Analysis of the class data

The analysis below is carried out by each participant in their own copy of the class data workbook, in parallel with the analysis shown on the projector.

Obtaining a copy. Open the class workbook at LINK 3, and save a personal copy (File → Save As → Save a copy). All work is carried out in the copy.

Step 1 · The inhibition cost of each participant. Add a column, Difference, containing for each participant the response time on incongruent trials minus the response time on congruent trials.

Step 2 · The t value. The t value requires the mean (M) and the standard error (SE) of the difference scores, and the standard error requires the standard deviation (SD) and the number of participants (N):

t = M / SE, with SE = SD / √N

Quantity Excel function
N =COUNT(range)
M =AVERAGE(range)
SD =STDEV.S(range)
SE SD divided by SQRT(N)
t M divided by SE

Step 3 · The p value. For a two-tailed test on paired data:

=T.TEST(incongruent range, congruent range, 2, 1)

The difference is statistically significant if p < .05.

Step 4 · Presentation. Create a column chart of the mean response time in each condition (y-axis beginning at zero), and a column chart of the inhibition costs sorted from smallest to largest, in which each bar represents one participant.

Questions. Is the mean inhibition cost positive? How many participants show a negative inhibition cost? Is the t value larger or smaller than that obtained for the spatial cueing effect, and why?

Points for discussion

  • Why is the Stroop effect so much more consistent across participants than many other effects?
  • In which sporting situations is a dominant response suppressed in favour of a less automatic one?
  • The task records response times for correct trials. Why might accuracy also need to be considered when interpreting an inhibition cost?

Additional exercises

  • Complete the flanker task (PsyToolkit) and calculate your inhibition cost for that task. Is it larger or smaller than your Stroop inhibition cost?
  • Complete the digit-letter task (PsyToolkit) and identify, from its results, a switch cost.
  • On paper, draw a column chart of the class mean response times for congruent and incongruent trials. Add a title, axis titles with units, and a y-axis beginning at zero.
If the task could not be completed The following values may be used: congruent trials 640 ms; incongruent trials 735 ms.
