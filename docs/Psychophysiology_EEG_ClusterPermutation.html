Permuation testing and Monte Carlo simulations

  1. compare the observed statistic against the empirical null distribution

  2. the emprical null distribution should be constructed using all possible reshuffles… or a large random sample of them (Monte Carlo)

  3. the empirical null distribution and the observed values can be constructed for any metric, not necessarily t-statistic (e.g., cluster metrics)

maxT

A solution to the jelly bean problem

  • For each iteration, you get a t-map across all features.

  • For each iteration, retain the maximum |t| across all features.

  • Across all iterations, build a distribution of maxT values

  • What survives is more extreme than the most extreme values obtained by chance (i.e., under the H0 of exchangeability) across all EEG dimensions

cluster forming and metrics

Effects tend to extend across neighbouring features (e.g., volume conduction, temporal autocorrelation, spectral smoothing).

Cluster forming

  1. threshold the uncorrected t-map (e.g., those corresponding to p < 0.05, uncorrected). The forming threshold is a parametric criterion (|t| ≥ 2.03, df = 35) used only to draw boundaries; the inference rests on the empirical null of the cluster metric.

  2. define adjacency (e.g., neighbouring time points, channels within a certain distance)

  3. separately for positive and negative t-values

  4. clusters = set of suprathreshold, adjacent, same-sign t-values

Cluster metrics

  • cluster extent/size/numerosity = number of features in the cluster

  • cluster height/most extreme value = most extreme t-value in the cluster

  • cluster mass = sum of t-values in the cluster

  • cluster mass (robust) = median of t-values in the cluster times the number of features in the cluster

Remember, the H0 distribution can be built with any metric. For example, cluster metrics.

Cluster-based permutation testing, with maxT correction

Cluster-based permutation testing, with maxT correction

On observed data:

  1. compute t-map across all features
  2. form clusters and compute cluster metrics

On each Monte Carlo iteration:

  1. shuffle the data according to the design
  2. compute t-map across all features
  3. form clusters and compute cluster metrics
  4. only retain the largest cluster metric (maxT)
  5. build the empirical H0 distribution of max cluster metrics

Test the observed cluster metrics against the empirical H0 distribution of max cluster metrics

Proportion of null maxima at or beyond an observed cluster metric = p-value for that cluster

Caveats

  1. Cluster-based permutation testing did not test the location or the boundaries of the cluster. It tested the existence of a cluster of a certain mass.

  2. Cluster forming depends on the threshold chosen (e.g., p < 0.05, uncorrected). Different thresholds can yield different clusters.

  3. Not well behaved where the same effect has different signs across the dimensions (e.g., N170 and VPP)


Diagonale: what it is

A MATLAB toolbox for permutation-based inference on EEG data.

Three inputs:

input content
Y observations × features (e.g., participant × condition rows; channel × time columns)
X design: contrasts, group codes, or continuous predictors
dataStruct what each row of Y is (participant, condition, group, …)

Scripting, not programming: the user sets configuration fields; the toolbox validates every field before anything runs.
